# 谈坛 / DisFly 2.0.24 (182)

- 菜单按用途分组，对齐图标和文字。搜索和发帖移至顶部，匿名浏览时可直接从账号卡片登录。
- 草稿箱支持编辑、继续保存和发布论坛网页草稿。「我的参与」可查看投票、辩论、悬赏和交易。用户主页可浏览对方的帖子。
- 支持浏览帖子标签、相关帖子、相关文章和门户评论。部分论坛可编辑个人资料、邀请好友和管理群组信息。
- 旧私信缓存无法迁移时，会提示并启用新缓存。密码库损坏时可以新建密码库，旧加密数据保留。
- 更新文件选择器和刷新组件，版块和帖子仍可下拉刷新、滚动加载。

## iOS

- Duo 展开时，菜单和登录页从右栏打开，左侧保留论坛列表。下拉刷新使用 iOS 转圈指示器。

## Android

- 对齐 Material 菜单的图标和箭头，保留下拉刷新和加载提示的深浅色配色。

# 谈坛 / DisFly 2.0.20 (178)

- 支持在允许音频附件的论坛录制语音主题和回复，可在输入栏试听，点发送箭头即可提交。
- 回帖草稿保留正文、引用和附件，重开 App 后仍可试听并发送语音。
- 发帖和回帖可选普通文件，遵守论坛的格式、大小和配额限制。改进附件和引用的深色显示。
- 新增按版块搜索、编辑帖子、活动报名审核和积分明细；补齐多选投票、悬赏和活动发帖。
- 改善动态照片预览、子版块筛选和论坛错误提示；推荐操作改用赞和踩图标。

## 下载

- `app-release.apk` 是已签名的 Android 安装包。
- `app-release.aab` 用于 Google Play，附带混淆映射和校验文件。
- iPhone 和 Apple Watch 测试版通过 TestFlight 分发。

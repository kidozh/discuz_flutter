# 谈坛 / DisFly 2.0.21 (179)

- 新增分类信息筛选、回帖奖励与抢楼提示，按论坛配置显示图片版块封面。
- 高级搜索支持作者、时间、版块与排序筛选，优化条件分组和结果展示；验证码继续转网页。
- 新增按论坛和账号分组的草稿箱，可恢复主题与回帖的正文、引用、文件和语音。
- Credit 页面新增积分规则与升级进度条，沿用论坛数据。
- 语音能力探测缓存一小时；优化输入栏中的录音、试听、删除与一键发送。
- 修复 Stage1st 等论坛的导读列表，区分正常空列表和接口异常。
- 内置浏览器离开论坛时显示站外提示，返回论坛后自动隐藏。

## iOS

- 统一 Cupertino 与 Liquid Glass 的加载指示器和全局提示，优化录音与语音草稿的原生图标和深色布局。

## Android

- 优化录音与语音草稿的 Material 图标、按钮对齐和深色显示。

# 谈坛 / DisFly 2.0.23 (181)

- 高级搜索保存历史和预设，可恢复版块、作者、时间和排序条件。验证码仍由论坛网页处理。
- 可静音单个帖子，按整个论坛或指定版块设置屏蔽词。
- 「我的活动」分开展示发起和报名的活动，点开可查看论坛的报名状态。
- 新增附件下载记录，可查看进度、重试失败下载、打开已下载文件并跳回原楼层。
- 收藏支持筛选更新、继续阅读和直达最新回复；附件总览可定位图片、文件和语音所在楼层。
- 投票结果会标记自己选过的选项，并增加群组、关注和论坛任务等入口。

# 谈坛 / DisFly 2.0.16 (174)

- 在「设置 → 论坛显示 → 图片加载 Cookie」选择「同站点」「总是允许」或「从不」。默认「同站点」，升级前关闭过此功能的用户保留为「从不」。
- 帖子正文、附件预览和大图按目标地址的 Cookie 范围加载，支持论坛通过同站点子域名托管图片，例如 Stage1st。
- 回复和发帖仅在论坛要求验证码时显示验证区域，并保留已输入的内容以便继续提交。

## 下载

- `app-release.apk` 是已签名的 Android 安装包。
- `app-release.aab` 用于 Google Play 发布，附带混淆映射和校验文件。
- `Runner-ios.tar.gz` 是未签名的 iOS 构建验证产物。可安装的 iPhone 和 Apple Watch 版本通过 TestFlight 分发。

# 谈坛 / DisFly 2.0.17 (175)

- 「设置 → 论坛显示 → 图片与附件 Cookie」同时控制图片和普通附件下载，默认「同站点」。
- 修复部分帖子图片附件的预览和原图加载，补齐 Discuz 原图地址解析与预览回退。
- 普通附件按每次跳转的目标地址检查 Cookie，论坛返回登录页时会提示下载失败。
- 从 pub.dev 官方源更新兼容的 Flutter 依赖。

## 下载

- `app-release.apk` 是已签名的 Android 安装包。
- `app-release.aab` 用于 Google Play 发布，附带混淆映射和校验文件。
- `Runner-ios.tar.gz` 是未签名的 iOS 构建验证产物。可安装的 iPhone 和 Apple Watch 版本通过 TestFlight 分发。

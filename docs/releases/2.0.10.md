# 谈坛 / DisFly 2.0.10 (167)

- 处理 [#21](https://github.com/kidozh/discuz_flutter/issues/21)：帖子正文支持系统长按选择、调整选区并复制；每条帖子的“更多”菜单新增“复制正文”，复制当前显示的原文或译文，去除 HTML 标记并保留段落换行。
- Material 帖子和回复使用标准卡片背景、间距与阴影；提升浅色和深色模式下的区分度。
- 修正 Cupertino 列表与回复的分隔线，统一导航栏间距和返回按钮；调整 Liquid Glass 卡片背景与圆角。
- iPad 分栏内使用 Flutter 绘制的导航和控件，规避实机上左侧内容空白、菜单无响应的可疑原生视图路径，保留玻璃卡片外观。此项仍需新版 TestFlight 在受影响实机上确认。
- 包含 Apple Watch 配套应用：通过配对 iPhone 查看热帖、提醒和私信，阅读全文与分页回复，并使用手表系统输入发送文字回复或私信。登录和验证码仍在手机处理。
- Android 新增可选的后台新帖提醒：默认关闭；以游客身份检查选中站点，在设备空闲、电量充足且联网时由系统调度，首次检查只建立基线，后续新帖去重提醒。
- 改进 AI 总结卡片、流式内容展示、帖子轮播布局、网易云音乐卡片和翻译入口。
- 补全 iOS 默认 Keychain 权限，保留已有加密数据；发布流程为手机和内嵌 Apple Watch 分别配置分发签名。

## 下载与测试

- `app-release.apk`：已签名 Android 安装包。
- `app-release.aab`：Google Play 发布包；混淆映射与校验值随版本提供。
- `Runner-ios.tar.gz`：用于构建兼容性验证的未签名 iOS 产物，不能直接安装；可安装版本通过 App Store Connect / TestFlight 单独发布。
- Apple Watch 依赖配对 iPhone 的初始化、登录状态和连接，不支持独立联网登录。
- Android 后台检查目标间隔为一小时，实际运行时机由系统决定。

验证：585 项 Flutter 回归测试、16 项 Python 发布预检测试及 7 项 Android 原生测试通过；静态分析无 error，仍有存量 warning / info。iPad 集成测试覆盖 Keylol 首页、四标签布局与菜单进入设置。

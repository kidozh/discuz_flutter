# 谈坛 / DisFly 2.0.22 (180)

- 发帖设置集中到弹层，可发布带选项图片的投票、填写分类信息并设置抢楼。投票上限和分类必填项按论坛配置。
- 投票选项的图片随草稿恢复，阅读图片投票时可点开原图。
- 发帖和回帖时输入 @ 可选择论坛好友；发送普通回帖后自动定位到新楼层。
- 回帖奖励确认页显示手续费和总扣分，获奖楼层采用更清楚的徽标。
- 辩论帖分别展示正反方观点和票数，版本欢迎页新增「本版新功能」。

## iOS

- 发帖设置和投票编辑采用 iOS 底部弹层，可从系统照片选择器添加选项图片。

## Android

- 发帖设置采用 Material 底部弹层，投票选图使用 Android 系统照片选择器。

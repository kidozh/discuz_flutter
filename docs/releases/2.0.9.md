# 谈坛 / DisFly 2.0.9 (165)

- 改进 iPhone Duo 的展开、折叠、安全区域和双栏导航，切换姿态时保留阅读位置、页面层级和输入状态。
- 强化帖子选中状态，使用深色背景；宽屏轮播限制单张宽度，并可同时展示多张卡片。
- 登录页支持滚动和键盘避让，改善小屏及大字体下的内容裁切。
- 正文支持长按选择并复制部分文字，包括行内格式、引用和表格。
- AI 总结在较短帖子上也可使用，支持流式显示、缓存与重复请求合并；Apple Intelligence 可用时默认开启，保留用户主动关闭的设置。
- 新增本机加密保存的 AI 对话历史，可查看、继续和删除对话。
- Android 翻译入口和结果增加 Google Translate 署名及说明。
- 隐藏论坛名称时，导航栏显示应用名称；改进回复目标隔离、图片上传和推送初始化。
- 更新 Flutter 及依赖，增加 Xcode / SDK 构建检查，防止意外混用旧工具链。

## 下载说明

- `app-release.apk`：已签名的 Android 安装包。
- `app-release.aab`：用于 Google Play 的发布包；对应的混淆映射为 `mapping.txt`，APK 对应 `apk-mapping.txt`。
- `SHA256SUMS.txt`：Android 发布文件校验值，构建信息见 `android-release-info.txt`。
- `Runner-ios.tar.gz`：GitHub CI 生成的未签名 iOS 编译产物，无法直接安装。该任务用于 SDK 兼容性检查；完整 iPhone Duo 屏幕支持须使用 Xcode 27.1 / iOS SDK 27.1 或更新版本进行签名归档。App Store / TestFlight 发布流程会单独严格检查 SDK。
- `Runner-ios-duo-sdk27.1.tar.gz`：使用 Xcode 27.1 / iOS SDK 27.1 编译的本机未签名发布产物，包含 Duo 原生支持，同样需要签名后才能安装。
- `tantan-app-store-zh-Hans.zip`：19 组中文原图与带标题展示图，涵盖普通 iPhone、Pro Max、11 / 13 英寸 iPad 和 Duo 内外屏。截图采集版本为 2.0.8+164，拍摄后已包含本次界面改动；原始版本信息保留在素材清单中。

本次安全存储升级包含旧版 Android 存储的迁移处理，不会自动重置已有密码库。历史测试版本中已损坏或丢失的密钥无法据此恢复。

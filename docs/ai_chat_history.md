# AI 对话历史

入口：设置 → 智能化 → AI 对话历史，也可从智能化页右上角的历史按钮进入。启用智能化且设备模型可用时，点击历史页的 + 开始对话。历史按最后回复时间排列，点击记录可查看并继续对话，也可单独删除。

记录只保存在本机的独立加密 Hive box 中，密钥通过现有系统安全存储管理；不自动清理，也不依赖论坛浏览历史开关。模型不可用或智能化关闭时仍能查看和删除记录，发送按钮禁用。新增功能只保存之后完成的对话，无法恢复过去没有存储的模型输出。

每次成功回复把问题和回答作为一轮原子保存。生成失败保留输入供重试；保存失败重试会复用已生成的回复。离开页面后正在执行的成功请求仍会保存结果。打开空对话不会创建历史记录。

继续对话时向 Foundation Models / Gemini Nano 发送最新问题和预算内完整的最近几轮；完整历史仍保存在本地。Android 使用 conversation 标记区分普通聊天与正文总结等任务，聊天会回答用户请求，正文任务继续将输入内容视为数据。

验证：`test/ai_chat_history_test.dart` 覆盖加密存储重开、更新排序、删除、最近上下文、续聊、生成/保存重试，以及 Material 和 Cupertino 中模型不可用时查看历史。
